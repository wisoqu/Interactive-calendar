# 🏫 Интерактивный Школьный Календарь (Classroom Calendar)

Продуктивный интерактивный календарь и планировщик для классов и школьных групп. Написан на современном **TypeScript** и спроектирован в уникальном, высококонтрастном дизайне с поддержкой темной и светлой тем, настраиваемой локализацией, гибкими правилами приватности, ограничением емкости классов и удобным пошаговым выбором дат и времени.

Проект представляет собой **Full-Stack веб-приложение (Express + Vite + React)** со встроенной локальной базой данных **SQLite** (`better-sqlite3`), разворачивающейся на том же сервере без необходимости внешних облачных сервисов или сложного окружения.

## 🚀 Установка и Развертывание в Production (1 клик)

Приложение разработано для максимальной простоты деплоя на ваш VPS (Ubuntu / Debian). Наиболее рекомендуемый способ — использование нашего скрипта автоматической установки. 

### Установка одной командой

Просто выполните следующую команду в терминале вашего сервера (желательно с правами `root` или через `sudo`):

```bash
bash <(curl -Ls https://raw.githubusercontent.com/wisoqu/Interactive-calendar/master/install.sh)
```

**Что сделает этот скрипт?**
1. Проверит наличие необходимых зависимостей (Git, Docker, Docker Compose).
2. Склонирует последнюю версию репозитория (по умолчанию в `/opt/interactive-calendar`).
3. Задаст вам несколько простых вопросов для настройки отправки писем (SMTP).
4. Автоматически соберет и запустит Docker-контейнеры.

### Настройка Почты (SMTP)
Во время работы скрипта вас попросят ввести данные от SMTP сервера. Это нужно для того, чтобы пользователи могли **восстанавливать забытые пароли**.
Если вы планируете использовать **Gmail**, учтите, что ваш обычный пароль от почты не подойдет. Вам нужно:
1. Зайти в настройки Google Аккаунта -> Безопасность.
2. Включить двухэтапную аутентификацию (если еще не включена).
3. Создать **App Password (Пароль приложения)** и использовать именно его при запросе `SMTP Password`.
4. В качестве `SMTP Host` указать `smtp.gmail.com`, а порт `587`.

Если вы не хотите сейчас настраивать почту, просто нажмите **Enter**, когда скрипт спросит `SMTP Host`, и этот шаг будет пропущен.

## 🔒 Настройка HTTPS (Reverse Proxy Nginx)

Для развертывания проекта в интернете на собственном домене и корректной работы безопасных сессий, настоятельно рекомендуется использовать HTTPS-соединение (порт 443).

1. **Установите Nginx и Certbot**:
   ```bash
   sudo apt-get update
   sudo apt-get install -y nginx certbot python3-certbot-nginx
   ```

2. **Создайте конфигурацию Nginx** (`/etc/nginx/sites-available/calendar`):
   ```nginx
   server {
       listen 80;
       server_name yourdomain.com; # замените на ваш домен

       location / {
           proxy_pass http://127.0.0.1:3000;
           proxy_http_version 1.1;
           proxy_set_header Upgrade $http_upgrade;
           proxy_set_header Connection 'upgrade';
           proxy_set_header Host $host;
           proxy_cache_bypass $http_upgrade;
           proxy_set_header X-Real-IP $remote_addr;
           proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
       }
   }
   ```

3. **Активируйте сайт и выпустите SSL-сертификат**:
   ```bash
   sudo ln -s /etc/nginx/sites-available/calendar /etc/nginx/sites-enabled/
   sudo nginx -t
   sudo systemctl reload nginx
   
   # Эта команда автоматически получит сертификат от Let's Encrypt и перенастроит Nginx на 443 порт (HTTPS):
   sudo certbot --nginx -d yourdomain.com
   ```

## 🎨 Особенности и Ключевые Функции

1. **Режимы отображения календаря**: Сетка Месяца (Month Grid) и Недельный/Таймлайн вид (Week & List View).
2. **Пошаговый Мастер Выбора Даты и Времени (Date & Time Wizard)**.
3. **Настройки Приватности и Лимитов Групп (Privacy & Capacity Limits)**:
   - **Закрытие класса (`is_closed`)**: Возможность заблокировать добавление новых участников.
   - **Максимум учеников (`max_members`)**: Автоматическое ограничение вместимости группы.
4. **Интерактивная Анимация Активной Группы**: Индикаторы статуса на главной странице (`🔒 Закрыт`, `👥 Лимит: N`).
5. **Гибкое управление ролями (RBAC)**: Создатель (Owner), Администратор (Admin), Участник (Member).
6. **Восстановление паролей**: Полноценная встроенная поддержка отправки 6-значных кодов подтверждения через SMTP.
7. **Безопасное подключение**: Добавление участников по уникальным сгенерированным инвайт-кодам.
8. **Горячие клавиши (Keyboard Ergonomics)** и **Мультиязычность (RU/EN)**.

## 💻 Технологический Стек

* **Frontend**: React 18, TypeScript, Tailwind CSS, Lucide Icons, Motion (анимации).
* **Backend**: Node.js (Express), `better-sqlite3` (высокопроизводительный драйвер SQLite), Nodemailer (отправка писем), `esbuild` для сборки бэкенда.
* **База данных**: SQLite (сохраняется на хосте через Docker Volume `calendar_db.sqlite`).
