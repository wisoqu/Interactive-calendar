# 🏫 Интерактивный Школьный Календарь (Classroom Calendar)

Продуктивный интерактивный календарь и планировщик для классов и образовательных групп. 

---

## 🎯 О проекте (Материалы для презентации)

**Цель проекта:** Создать максимально легковесное, быстрое и удобное приложение для совместного планирования школьных мероприятий, расписаний и событий внутри изолированных групп (классов).

**Ключевые решаемые проблемы:**
- **Хаос в чатах:** Замена бесконечных переписок в мессенджерах на структурированный и понятный календарь.
- **Управление доступом:** Строгий контроль того, кто может просматривать расписание и добавлять события.
- **Простота развертывания:** Система не требует тяжелых облачных баз данных и легко запускается даже на самом дешевом VPS сервере (с 512 МБ ОЗУ).

---

## ✨ Основной функционал (Features)

### 1. Умный Календарь и Планирование
- **Два режима просмотра**: Классическая сетка на месяц (Month Grid) для оценки общей картины и компактный список (List View) для фокуса на ближайших событиях.
- **Пошаговый мастер создания (Date & Time Wizard)**: Интуитивно понятный интерфейс создания событий, разбитый на шаги. Предотвращает ошибки при вводе времени и дат.
- **Интерактивность**: Плавные анимации переходов, поддержка как светлой, так и темной темы с визуальным откликом на действия пользователя.

### 2. Управление Группами (Классами)
- **Изолированные пространства**: Каждый класс имеет свой уникальный сгенерированный инвайт-код для безопасного вступления.
- **Лимиты и Приватность**: Возможность установить жесткий лимит участников (например, не больше 30 человек) и режим «Закрытого класса» (вступление блокируется для всех).
- **Визуальные индикаторы статуса**: Если группа переполнена или закрыта, это наглядно отображается в интерфейсе (`🔒 Закрыт`, `👥 Лимит: N`).

### 3. Безопасность и Аккаунты
- **Защищенная аутентификация**: Использование хеширования для паролей, безопасные сессии на основе cookies (Secure & HttpOnly).
- **Восстановление доступа**: Встроенная система отправки 6-значных OTP кодов на почту (интеграция по SMTP).
- **Эргономика**: Поддержка горячих клавиш для быстрой навигации и полная локализация.

## 💻 Архитектура и Технологический стек

Проект спроектирован как **Full-Stack веб-приложение**, нацеленное на максимальную производительность при минимальном потреблении серверных ресурсов.

### Frontend (Клиентская часть)
- **React 18 & TypeScript**: Обеспечивают надежность бизнес-логики, строгую типизацию и современный компонентный подход.
- **Vite**: Сборщик следующего поколения. Обеспечивает мгновенный холодный старт при разработке и сильно оптимизированную сборку для продакшена.
- **Tailwind CSS**: Утилитарный CSS-фреймворк для создания уникального высококонтрастного дизайна.
- **Motion (Framer Motion)**: Реализация плавных 60fps анимаций без просадки производительности браузера.
- **Lucide React**: Современная, легковесная и масштабируемая библиотека векторных иконок.

### Backend (Серверная часть)
- **Node.js & Express**: Проверенный временем веб-фреймворк для обработки REST API запросов, работы с куки и сессиями.
- **Nodemailer**: Модуль для надежной транзакционной рассылки писем (восстановление пароля).
- **esbuild & tsx**: Инструменты для моментальной компиляции TypeScript-кода на стороне сервера.

### База Данных (Главная архитектурная фича)
- **SQLite (better-sqlite3)**: Одно из главных архитектурных решений. Мы отказались от тяжелых СУБД (PostgreSQL/MySQL) в пользу встраиваемой БД SQLite. 
  * *Почему это круто?* База хранит все данные в одном файле (`calendar_db.sqlite`), работает прямо внутри процесса Node.js без сетевых задержек и сложных настроек. Потребляет минимум оперативной памяти, что делает приложение идеальным для запуска на "копеечных" серверах. Библиотека `better-sqlite3` гарантирует высочайшую скорость работы за счет синхронного исполнения.

## 🚀 Установка и Развертывание в Production (1 клик)

Приложение разработано для максимальной простоты деплоя на ваш VPS (Ubuntu / Debian). Наиболее рекомендуемый способ — использование нашего скрипта автоматической установки. 

### Установка одной командой

Просто выполните следующую команду в терминале вашего сервера (желательно с правами `root` или через `sudo`):

```bash
bash <(curl -Ls https://raw.githubusercontent.com/wisoqu/Interactive-calendar/master/install.sh)
```

**Что сделает этот скрипт?**
1. Проверит наличие необходимых зависимостей (Git, Docker, Docker Compose).
2. Склонирует последнюю версию репозитория (по умолчанию в `/opt/interactive-calendar`).
3. Задаст вам несколько простых вопросов для настройки отправки писем (SMTP).
4. Автоматически соберет и запустит Docker-контейнеры.

### Настройка Почты (SMTP)
Во время работы скрипта вас попросят ввести данные от SMTP сервера. Это нужно для того, чтобы пользователи могли **восстанавливать забытые пароли**.
Если вы планируете использовать **Gmail**, учтите, что ваш обычный пароль от почты не подойдет. Вам нужно:
1. Зайти в настройки Google Аккаунта -> Безопасность.
2. Включить двухэтапную аутентификацию (если еще не включена).
3. Создать **App Password (Пароль приложения)** и использовать именно его при запросе `SMTP Password`.
4. В качестве `SMTP Host` указать `smtp.gmail.com`, а порт `587`.

Если вы не хотите сейчас настраивать почту, просто нажмите **Enter**, когда скрипт спросит `SMTP Host`, и этот шаг будет пропущен.

## 🔒 Настройка HTTPS (Reverse Proxy Nginx)

Для развертывания проекта в интернете на собственном домене и корректной работы безопасных сессий, настоятельно рекомендуется использовать HTTPS-соединение (порт 443).

1. **Установите Nginx и Certbot**:
   ```bash
   sudo apt-get update
   sudo apt-get install -y nginx certbot python3-certbot-nginx
   ```

2. **Создайте конфигурацию Nginx** (`/etc/nginx/sites-available/calendar`):
   ```nginx
   server {
       listen 80;
       server_name yourdomain.com; # замените на ваш домен

       location / {
           proxy_pass http://127.0.0.1:3000;
           proxy_http_version 1.1;
           proxy_set_header Upgrade $http_upgrade;
           proxy_set_header Connection 'upgrade';
           proxy_set_header Host $host;
           proxy_cache_bypass $http_upgrade;
           proxy_set_header X-Real-IP $remote_addr;
           proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
       }
   }
   ```

3. **Активируйте сайт и выпустите SSL-сертификат**:
   ```bash
   sudo ln -s /etc/nginx/sites-available/calendar /etc/nginx/sites-enabled/
   sudo nginx -t
   sudo systemctl reload nginx
   
   # Эта команда автоматически получит сертификат от Let's Encrypt и перенастроит Nginx на 443 порт (HTTPS):
   sudo certbot --nginx -d yourdomain.com
   ```
